## Грамматика (коротко)

Ish = работа. Ishlamoq = работать. Ishlayman = я работаю (суффикс -yman для первого лица). Ishlaysiz = вы работаете. Siz qaerda ishlaysiz? = Где вы работаете?

Kasb = профессия. Siz kim bo'lib ishlaysiz? = Кем вы работаете? Это вопрос из урока 2 (знакомство). Профессии: muhandis = инженер, o'qituvchi = учитель, shifokor = врач, haydovchi = водитель, dasturchi = программист.

Hamkasb = коллега (ham = вместе + kasb = профессия). Mening hamkasbim = мой коллега. Rahbar = начальник/руководитель. Xodim = сотрудник.

Ish vaqti = рабочее время (ish = работа + vaqt = время). Время из урока 9: Soat to'qqizdan beshgacha = с девяти до пяти. Суффикс -dan = от/с, суффикс -gacha = до.

Dam olish = отдых (dam olmoq = отдыхать). Dam olish kuni = выходной день (kun = день + суффикс -i). Shanba va yakshanba dam olish kunlari = суббота и воскресенье выходные дни.

## Мини-диалог

— Siz qaerda ishlaysiz?
— Men ofisda ishlayman. Siz-chi?
— Men maktabda ishlayman. O'qituvchiman.
— Ish vaqtingiz qanday?
— Soat sakkizdan ikkigacha. Dam olish kuni — yakshanba.
— Yaxshi! Mening ham yakshanbada dam olaman.
