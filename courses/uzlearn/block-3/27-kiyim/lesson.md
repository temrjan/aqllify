## Грамматика (коротко)

Kiyim = одежда (общее слово). Kiymoq = надевать. Kiyib ko'raman = примерю (буквально: надев посмотрю). Ko'rmoq = смотреть/видеть, суффикс -aman = я.

Oyoq = нога, oyoq kiyim = обувь (буквально: одежда для ног). Bosh kiyim = головной убор (bosh = голова).

Другие предметы одежды: palto = пальто, kurtka = куртка, shapka = шапка, paypoq = носки, ko'ylak = рубашка/блузка.

Цвета из урока 10 описывают одежду: qizil ko'ylak = красная рубашка, qora shim = чёрные брюки, oq ko'ynak = белое платье. Цвет ставится перед существительным.

Размеры из урока 11: katta = большой, kichik = маленький. Bu katta = это большое, kichikroq bormi? = поменьше есть? Суффикс -roq означает сравнительную степень: katta + roq = kattaroq (побольше).

Спираль из урока 14: bormi? (есть?), bering (дайте), necha so'm? (сколько стоит?). Bu ko'ylak necha so'm? = сколько стоит эта рубашка?

## Мини-диалог

— Kechirasiz, qizil ko'ylak bormi?
— Ha, bor. Qanday razmer?
— Kichik razmer. Kiyib ko'raman.
— Marhamat. Bu yerda ko'zgu bor.
— Yaxshi! Bu necha so'm?
— O'n besh ming so'm.
— Olaman. Rahmat!
