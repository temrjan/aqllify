## Грамматика (коротко)

Pochta = почта. Pochtaga boraman = я пойду на почту. Pochtada = на почте (суффикс -da для местоположения).

Jo'natma = посылка (от jo'natmoq = отправлять). Jo'natma jo'natmoqchiman = я хочу отправить посылку. Jo'natmoqchiman = я хочу отправить (суффикс -moqchiman для намерения).

Manzil = адрес. Manzilingiz nima? = Какой ваш адрес? Manzilni yozing = напишите адрес. Вспомни из урока 18: направления o'ngga, chapga, to'g'ri boring помогут объяснить где находится адрес.

Yetkazib berish = доставка (буквально: доставить и дать). Yetkazib berish bormi? = Есть доставка? Necha kunda yetkazib berasiz? = За сколько дней доставите? Числа из урока 6 нужны для сроков.

Xat = письмо. Xat jo'natmoqchiman = я хочу отправить письмо. Xat olmoq = получить письмо. Xat qancha turadi? = Сколько стоит письмо?

Спираль: числа для стоимости и сроков (урок 6), деньги для оплаты (урок 15), направления для объяснения адреса (урок 18).

## Мини-диалог

— Salom! Jo'natma jo'natmoqchiman.
— Manzilni yozing, iltimos.
— Mana, yozib bo'ldim. Qancha turadi?
— Yigirma besh ming so'm.
— Yetkazib berish necha kunda?
— Uch kunda yetkazamiz.
— Yaxshi. Naqd pul bilan to'layman.
— Marhamat. Chekingiz.
— Rahmat!

## Задание на дом

O'z manzilingizni o'zbekcha yozing: shahar, ko'cha, uy raqami. Keyin yozing: "Men (nima) jo'natmoqchiman. Manzil — ..." Masalan: "Men xat jo'natmoqchiman. Manzil — Toshkent, Navoiy ko'chasi, 15-uy."
