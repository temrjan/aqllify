## Грамматика (коротко)

Maktab = школа. Maktabga boraman = я иду в школу. Суффикс -ga указывает направление (куда?): maktab + ga = maktabga. Maktabda = в школе (суффикс -da означает место, где находишься).

O'qituvchi = учитель, от глагола o'qimoq (читать/учиться). O'quvchi = ученик. O'qituvchi o'qitadi = учитель учит. O'quvchi o'qiydi = ученик учится.

Dars = урок. Darslar = уроки (суффикс -lar для множественного числа). Dars soat nechada? = Во сколько урок? Вспомни вопрос Soat necha? из урока 9.

Baho = оценка. Yaxshi baho = хорошая оценка. Besh = пятёрка (высшая оценка), помним числа из урока 5. Beshlik baho = отличная оценка.

Uy vazifasi = домашнее задание (буквально: задание дома). Uy = дом, vazifa = задание. Uy vazifasini qildim = я сделал домашнее задание.

Спираль: числа из урока 5 для оценок, дни недели из урока 8 для расписания, время из урока 9 для расписания уроков.
