## Фразы

| Узбекский | Кириллица | Русский |
|-----------|-----------|---------|
| Shifokor | Шифокор | Врач |
| Kasalxona | Касалхона | Больница |
| Og'riydi | Оғрийди | Болит |
| Dori ichaman | Дори ичаман | Я принимаю лекарство |
| Sog'ayib keting | Соғайиб кетинг | Выздоравливайте |

## Грамматика (коротко)

Shifokor = врач/доктор. Kasalxona = больница (kasal = больной + xona = помещение). Kasal = больной (прилагательное): Men kasalman = я болен. Sog'lom = здоровый: Men sog'lom = я здоров.

Og'riydi = болит. Перед этим словом ставится часть тела с суффиксом -im: boshim og'riydi = у меня болит голова, qo'lim og'riydi = у меня болит рука (qo'l = рука). Эта конструкция знакома из урока 22 (аптека).

Dori = лекарство (из урока 22). Ichmoq = пить/принимать. Dori ichaman = я принимаю лекарство (ich + aman = первое лицо). Dori iching = принимайте лекарство (вежливая форма).

Sog'ayib keting = выздоравливайте (пожелание). Sog'aymoq = выздоравливать. Keting = уходите (здесь усиливает пожелание). Это вежливая форма, как Iltimos из урока 4.

Спираль: Ha / Yo'q из урока 3 для ответов на вопросы врача (Boshingiz og'riydimi? Ha / Yo'q). Kechirasiz и Iltimos из урока 4 для вежливого обращения. Dori bering из урока 22.

## Мини-диалог

— Kechirasiz, shifokor bormi?
— Ha, bor. Nima bo'ldi?
— Boshim og'riydi va isitmam bor.
— Marhamat, o'tiring. Shifokor hozir keladi.
— Rahmat!
— Dori iching va dam oling. Sog'ayib keting!

## Задание на дом

Выучи три фразы для визита к врачу: "Boshim og'riydi" (голова болит), "Isitmam bor" (есть температура), "Dori bering, iltimos" (дайте лекарство). Произнеси каждую вслух.
