## Грамматика (коротко)

Savdo = торговля, markaz = центр. Savdo markaz = торговый центр. Savdo markazga boramiz = мы пойдём в ТЦ.

Qavat = этаж. Birinchi qavat = первый этаж, ikkinchi qavat = второй этаж, uchinchi qavat = третий этаж. Порядковые числа образуются суффиксом -inchi: bir + inchi = birinchi, ikk + inchi = ikkinchi (из чисел урока 6).

Kiyinish xonasi = примерочная (буквально: комната для одевания). Kiyinish = одевание, xona = комната, -si = суффикс принадлежности. Kiyinish xonasi qayerda? = Где примерочная?

Chegirma = скидка. Chegirma bormi? = Есть скидка? Yigirma foiz chegirma = 20% скидка. Foiz = процент.

O'lcham = размер. O'lchamingiz necha? = Какой ваш размер? Katta o'lcham = большой размер, kichik o'lcham = маленький размер (прилагательные из урока 11).

Спираль: числа для этажей и скидок (урок 6), покупки в магазине (урок 14), оплата (урок 15), одежда (урок 27).

## Мини-диалог

— Savdo markazga boramiz! Kiyim kerak.
— Kiyim do'koni nechinchi qavatda?
— Ikkinchi qavatda. Yuringlar!
— Bu ko'ylak yoqdi. O'lchamim bor?
— Ha, bor. Kiyinish xonasi u yerda.
— Zo'r! Chegirma bormi?
— Ha, o'n besh foiz chegirma.
— Ajoyib! Karta bilan to'layman.
