## Грамматика (коротко)

Ob-havo = погода. Bugun ob-havo qanday? = Какая сегодня погода? Qanday = какой/какая.

Issiq = жарко/горячий, Sovuq = холодно/холодный. Эти слова знакомы из урока 11 (прилагательные). В контексте погоды: Bugun issiq = сегодня жарко, Bugun sovuq = сегодня холодно.

Yomg'ir = дождь. Yog'moq = падать (об осадках). Yomg'ir yog'yapti = дождь идёт (сейчас). Суффикс -yapti означает действие прямо сейчас (настоящее продолженное).

Qor = снег. Qor yog'yapti = идёт снег. Bulut = облако. Bugun bulutli = сегодня облачно. Суффикс -li означает наличие чего-то: bulut + li = облачный.

Fasllar = времена года: bahor = весна, yoz = лето, kuz = осень, qish = зима. Yozda issiq = летом жарко. Qishda sovuq = зимой холодно. Суффикс -da означает в/во время.

Спираль: дни недели из урока 8 (Dushanba sovuq bo'ladi = в понедельник будет холодно), время суток из урока 9 (Ertalab sovuq, tushda issiq = утром холодно, днём жарко).
