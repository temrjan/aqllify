## Грамматика (коротко)

Hafta = неделя, oxiri = конец. Hafta oxiri = конец недели, выходные. Shanba va Yakshanba = суббота и воскресенье (из урока 8).

Суффикс -miz / -amiz означает «мы»: boramiz = мы пойдём (bor + amiz), qilamiz = мы сделаем (qil + amiz), olamiz = мы возьмём / отдохнём. Сравни с формой -aman (я): boraman = я пойду, boramiz = мы пойдём.

Reja = план. Rejam bor = у меня есть план. Hafta oxiriga reja = план на выходные. Суффикс -ga для направления/цели.

Sayil = прогулка. Sayil qilmoq = гулять. Dam olmoq = отдыхать. Dam = отдых, olmoq = брать. Буквально: «брать отдых».

Спираль: дни недели (урок 8) для обсуждения выходных, время (урок 9) для планов, хобби (урок 32) для занятий в выходные.

## Мини-диалог

— Hafta oxiri nima qilamiz?
— Shanbada parkga boramiz. Sayil qilamiz.
— Soat nechada?
— Soat o'nda, ertalab.
— Yakshanbada-chi?
— Dam olamiz. Kitob o'qiyman, musiqa tinglayman.
— Zo'r reja!

## Задание на дом

Hafta oxiriga reja tuz: Shanba va Yakshanbada nima qilasiz? Har bir kun uchun 2 ta ish yoz. Masalan: "Shanbada parkga boramiz, soat uchda."
