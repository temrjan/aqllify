## Фразы

| Узбекский | Кириллица | Русский |
|-----------|-----------|---------|
| Non | Нон | Хлеб / Лепёшка |
| Go'sht | Гўшт | Мясо |

| Meva | Мева | Фрукт |
| Pishirmoq | Пиширмоқ | Готовить |

## Грамматика (коротко)

Non = хлеб/лепёшка. Это слово уже знакомо из урока 21 (чайхана): Non bering = дайте лепёшку. В узбекской культуре нон подаётся к каждому приёму пищи.

Go'sht = мясо. Mol go'shti = говядина (mol = корова), tovuq go'shti = курятина (tovuq = курица), qo'y go'shti = баранина (qo'y = баран).

Sabzavot = овощи. Основные овощи: sabzi = морковь, piyoz = лук, pomidor = помидор, bodring = огурец. Meva = фрукт: olma = яблоко, uzum = виноград, anor = гранат.

Pishirmoq = готовить. Pishiraman = я готовлю (суффикс -aman для первого лица). Onam palov pishiradi = мама готовит плов (-adi для третьего лица).

Вкус: mazali = вкусно (из урока 20), shirin = сладкий, achchiq = острый/горький, sho'r = солёный. Meva shirin = фрукты сладкие. Palov mazali = плов вкусный.

Спираль: числа из урока 5 для количества (uchta non = три лепёшки), Bering и Mazali из уроков 20-21.

## Мини-диалог

— Bugun nima pishiramiz?
— Palov pishiramiz! Go'sht va sabzi kerak.
— Non bormi?
— Yo'q, non kerak. Ikkita non olib kelamiz.
— Mazali bo'ladi!
— Ha, juda mazali!

## Задание на дом

Составь меню обеда из трёх блюд по-узбекски, используя слова: non, go'sht, sabzavot, meva. Например: "Birinchi — palov, ikkinchi — sabzavot, uchinchi — meva."
