## Фразы

| Узбекский | Кириллица | Русский |
|-----------|-----------|---------|
| Gaplashaylik | Гаплашайлик | Давайте поговорим |
| Fikringiz qanday? | Фикрингиз қандай? | Что вы думаете? |
| Qiziq | Қизиқ | Интересно |
| Roziman | Розиман | Я согласен |
| Ko'rishguncha | Кўришгунча | До встречи |

## Грамматика (коротко)

Gaplashaylik = давайте поговорим (от gaplashmoq = разговаривать). Суффикс -aylik означает предложение действия вместе (мы-форма предложения): boraylik = давайте пойдём, qilaylik = давайте сделаем. Suhbat = беседа. Suhbatlashaylik = давайте побеседуем.

Fikringiz qanday? = Что вы думаете? Fikr = мнение, мысль. Fikringiz = ваше мнение (суффикс -ingiz для вежливого обращения). Mening fikrimcha = по моему мнению. Fikrim bor = у меня есть мнение.

Roziman = я согласен (rozi = согласный + man). Rozi emasman = я не согласен. To'g'ri (урок 3) = правильно, верно. Используй для подтверждения: Ha, roziman! = Да, я согласен! Yo'q, rozi emasman = нет, я не согласен.

Qiziq = интересно (прилагательное и наречие). Juda qiziq! = Очень интересно! Qiziqarli = интересный (из урока 32). Bu mavzu qiziq = эта тема интересная.

Ko'rishguncha = до встречи (от ko'rishmoq = видеться + суффикс -guncha = пока не). Xayr (урок 1) = до свидания. Ko'rishguncha более тёплое прощание, чем Xayr. Используется когда знаешь что увидишься снова.

Полезные фразы для поддержания разговора: Aytingchi = скажите-ка, Rostdanmi? = Правда?, Shunaqa = вот так, именно так. Ob-havo (урок 28) хорошая тема для начала разговора. Ish (урок 30) и oila (урок 7) частые темы бесед.

Спираль: приветствия (урок 1) для начала разговора, знакомство (урок 2) для представления, вежливость (урок 4) для этикета, семья (урок 7) как тема беседы, погода (урок 28) как тема, работа (урок 30) как тема, эмоции (урок 46) для выражения чувств.

## Мини-диалог

— Salom! Yaxshimisiz?
— Yaxshi, rahmat! Bugun ob-havo yaxshi, to'g'rimi?
— Ha, juda issiq! Gaplashaylik biroz.
— Albatta! Ishlar qanday?
— Yaxshi, rahmat. Yangi loyiham bor. Fikringiz qanday?
— Juda qiziq! Roziman, yaxshi reja.
— Rahmat! Endi ketishim kerak.
— Yaxshi, ko'rishguncha!

## Задание на дом

Biror tanishingiz bilan o'zbekcha suhbat qur: salomlash, ob-havo haqida gapir, ish yoki oila haqida so'ra, fikr bildir. Kamida 6 ta gap ishlat. Oxirida "Ko'rishguncha!" de.
