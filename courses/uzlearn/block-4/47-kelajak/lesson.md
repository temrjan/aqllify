## Фразы

| Узбекский | Кириллица | Русский |
|-----------|-----------|---------|
| Xohlayman | Хоҳлайман | Я хочу |
| Rejalashtiraman | Режалаштираман | Я планирую |
| Orzu qilaman | Орзу қиламан | Я мечтаю |
| Bo'ladi | Бўлади | Будет / Получится |
| Harakat qilaman | Ҳаракат қиламан | Я постараюсь |

## Грамматика (коротко)

Xohlayman = я хочу (от xohlamoq = хотеть). Nima xohlaysiz? = Что вы хотите? Xohlayman + глагол с суффиксом -moqchi: Bormoqchiman = я хочу пойти. O'qimoqchiman = я хочу учиться. Суффикс -(a)man указывает на первое лицо.

Rejalashtiraman = я планирую (от reja = план, из урока 33). Kelajakka rejalashtiraman = планирую на будущее. Ish rejam bor = у меня есть рабочий план (ish из урока 30). Hafta oxiriga reja (урок 33) = план на выходные.

Orzu qilaman = я мечтаю (orzu = мечта + qilaman = делаю). Mening orzum = моя мечта. Orzu qilaman + глагол: sayohat qilishni orzu qilaman = мечтаю путешествовать.

Bo'ladi = будет, получится (от bo'lmoq = быть, становиться). Hammasi yaxshi bo'ladi = всё будет хорошо. Bo'ladi используется как утвердительный ответ: Ertaga kelingmi? Bo'ladi! = Придёте завтра? Ладно! Yaxshi bo'ladi = будет хорошо.

Harakat qilaman = я постараюсь (harakat = усилие, попытка). Harakat qilib ko'raman = попробую (буквально: попытаюсь и посмотрю). Используется когда не уверен в результате, но готов стараться.

Спираль: знакомство (урок 2) для рассказа о себе и планах, работа (урок 30) для карьерных планов, выходные (урок 33) для ближних планов, путешествия (урок 43) для планов на поездки.

## Мини-диалог

— Kelajakda nima qilmoqchisiz?
— O'qishni davom ettirmoqchiman. Dasturchiman, lekin ingliz tilini o'rganaman.
— Zo'r reja! Qachon boshlaysiz?
— Kelasi oyda rejalashtiraman.
— Hammasi yaxshi bo'ladi!
— Rahmat! Harakat qilaman.

## Задание на дом

Kelajakka 3 ta reja yoz: bitta yaqin (bu hafta), bitta o'rta (bu oy), bitta uzoq (bu yil). Masalan: "Bu hafta kitob o'qiyman. Bu oy ingliz tilini o'rganaman. Bu yil sayohat qilishni orzu qilaman."
