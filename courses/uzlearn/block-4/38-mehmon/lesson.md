## Грамматика (коротко)

Mehmon = гость. Mehmonlar = гости (суффикс -lar для множественного числа). Mehmonxona = гостиная (из урока 25: mehmon + xona = комната для гостей). В узбекской культуре гость считается священным: Mehmon otangdan ulug' = Гость выше отца.

Keling, marhamat = проходите, пожалуйста. Keling = приходите (вежливая форма глагола kelmoq). Marhamat уже знаком из урока 4 (вежливость). Keling сочетается с marhamat для тёплого приглашения.

Uyga taklif qilaman = приглашаю домой. Taklif qilmoq = приглашать. Uyga = домой (суффикс -ga для направления, знаком из уроков транспорта). Sizni uyga taklif qilaman = я вас приглашаю домой (sizni = вас).

Dasturxon = скатерть, накрытый стол. В узбекской традиции dasturxon стелется на пол или на низкий столик. Dasturxon tayyor = стол накрыт (tayyor = готово). На dasturxon всегда есть non (хлеб, из урока 26), meva (фрукты), choy (чай, из урока 21).

Qoling = оставайтесь (вежливая просьба). Yana qoling = побудьте ещё. В Узбекистане принято настойчиво просить гостя остаться. Когда гость собирается уходить, хозяин говорит: Qoling, choy iching! = Оставайтесь, попейте чаю!

Спираль: приветствия из урока 1 (Assalomu alaykum при входе), вежливость из урока 4 (Marhamat, Rahmat), семья из урока 7 (onam, otam), еда из урока 26 (non, go'sht, palov).

## Мини-диалог

— Assalomu alaykum! Keling, marhamat!
— Vaalaykum assalom! Rahmat, juda xursandman.
— Dasturxon tayyor. O'tiring, iltimos.
— Voy, qancha ovqat! Non, palov, meva...
— Marhamat, oling! Onam pishirgan.
— Juda mazali! Rahmat!
— Qoling, choy iching!
— Rahmat, lekin ketishim kerak. Xayr!

## Задание на дом

Напиши приглашение другу в гости по-узбекски: поприветствуй, пригласи домой и опиши, что будет на столе. Используй: Salom, uyga taklif qilaman, dasturxon, non, choy. Например: "Salom! Sizni uyga taklif qilaman. Dasturxonda palov va choy bor."
