## Грамматика (коротко)

Qo'shni = сосед. Qo'shnilar = соседи (суффикс -lar). Qo'shnimiz = наш сосед (суффикс -miz для нашего). Yonginamizda = рядом с нами. Qo'shni yaxshi odam = сосед хороший человек.

Yordam so'rayman = прошу помощи. Yordam = помощь. So'ramoq = просить. Yordam bering = помогите (вежливая просьба, из урока 4: Iltimos, yordam bering). Yordam beray = давайте я помогу. Yordam kerakmi? = Нужна помощь?

Shovqin = шум. Shovqin qilmang = не шумите (суффикс -mang для отрицательной просьбы). Shovqin ko'p = много шума. Tinch = тихо/спокойно. Bu yerda tinch = здесь тихо. Вопрос из урока 3: Shovqin bormi? = Есть шум?

Uzr so'rayman = прошу прощения / извиняюсь. Uzr = извинение. Более вежливая форма, чем Kechirasiz (из урока 4). Uzr so'rayman, shovqin qildik = извините, мы шумели. Hech gap emas = не за что / ничего страшного (из урока 4).

Ko'chada = на улице (ko'cha = улица, суффикс -da для места, как в уроке 25: xonada = в комнате). Ko'chaga chiqmoq = выйти на улицу (-ga для направления). Bizning ko'chamiz = наша улица.

Спираль: приветствия из урока 1 для соседского общения, вопросы ha/yo'q из урока 3, вежливость из урока 4 (Kechirasiz, Iltimos), дом из урока 25 (uy, xona).

## Мини-диалог

— Salom, qo'shni!
— Salom! Yaxshimisiz?
— Yaxshi, rahmat. Kechirasiz, bir narsa so'ramoqchiman.
— Marhamat, tinglayapman.
— Tuz bormi? Tuzimiz tugadi.
— Ha, bor. Marhamat, oling.
— Rahmat! Uzr, bezovta qildim.
— Hech gap emas! Qo'shnilar yordam berishadi.

## Задание на дом
