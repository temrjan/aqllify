## Фразы

| Узбекский | Кириллица | Русский |
|-----------|-----------|---------|
| Tug'ilgan kun muborak | Туғилган кун муборак | С днём рождения |
| To'y muborak | Тўй муборак | Поздравляю со свадьбой |
| Sovg'a | Совға | Подарок |
| Tilaklarim | Тилакларим | Мои пожелания |
| Baxtli bo'ling | Бахтли бўлинг | Будьте счастливы |

## Грамматика (коротко)

Tug'ilgan kun muborak = с днём рождения (буквально: рождённый день благословенный). Tug'ilgan kun = день рождения. Muborak = благословенный (знакомо из урока 40: Bayram muborak). Tug'ilgan kuningiz muborak! = С вашим днём рождения!

To'y muborak = поздравляю со свадьбой. To'y = свадьба/торжество. Узбекская свадьба — большое событие, приглашают сотни гостей. To'y qachon? = Когда свадьба? To'yga taklif qilaman = приглашаю на свадьбу.

Sovg'a = подарок. Sovg'a bermoq = дарить подарок. Bu sizga sovg'a = это вам подарок. Sovg'angiz uchun rahmat = спасибо за ваш подарок (uchun = за). Числа из урока 5 помогут назвать возраст: Necha yoshdasiz? = Сколько вам лет? O'n besh yoshdaman = мне 15 лет.

Tilaklarim = мои пожелания (tilak = пожелание, суффикс -lar для множественного числа, -im для моего). Eng yaxshi tilaklarim = мои лучшие пожелания. Sizga tilaklarim = мои пожелания вам.

Baxtli bo'ling = будьте счастливы. Baxtli = счастливый (baxt + суффикс -li). Bo'ling = будьте (вежливая форма от bo'lmoq = быть). Sog'lom bo'ling = будьте здоровы. Omadli bo'ling = будьте удачливы. Doim baxtli bo'ling = будьте всегда счастливы.

Спираль: числа из урока 5 для возраста, семья из урока 7 (oila, aka, opa), праздники из урока 40 (muborak, tabriklayman, baxt tilayman).

## Мини-диалог

— Tug'ilgan kun muborak, Sardor!
— Katta rahmat! Juda xursandman!
— Mana, sizga sovg'a.
— Voy, rahmat! Ochsam bo'ladimi?
— Ha, marhamat, oching!
— Juda chiroyli! Eng yaxshi sovg'a!
— Baxtli bo'ling! Tilaklarim — sog'lik va omad!
— Rahmat, do'stim!

## Задание на дом

Do'stingizga tug'ilgan kun tabrigi yozing. Sovg'a nima ekanini ayting va tilak bildiring. Masalan: "Tug'ilgan kun muborak! Mana, sizga sovg'a — yangi kitob. Baxtli bo'ling! Sog'lik va omad tilayman!"
