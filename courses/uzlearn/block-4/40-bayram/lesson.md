## Грамматика (коротко)

Bayram = праздник. Bayram muborak! = С праздником! (muborak = благословенный). Bayram kuni = в день праздника (kuni = день, из урока 8). Bayramda = в праздник (суффикс -da для времени/места).

Navro'z = Навруз, праздник весеннего равноденствия (21 марта). Это главный народный праздник Узбекистана. Navro'z muborak! = С Наврузом! Традиционное блюдо Навруза: sumalak (суманак) — сладкое блюдо из проросшей пшеницы. На Навруз готовят palov (из урока 26) и накрывают богатый dasturxon.

Ro'za hayit = Рамадан Хайит (Ид аль-Фитр), праздник окончания поста. Qurbon hayit = Курбан Хайит (Ид аль-Адха), праздник жертвоприношения. Hayit muborak! = С праздником Хайит! В эти дни семья (из урока 7) собирается вместе.

Tabriklayman = поздравляю (от tabriklamoq = поздравлять). Sizni tabriklayman! = Поздравляю вас! Sizni bayram bilan tabriklayman = поздравляю вас с праздником. Bilan = с (предлог).

Baxt tilayman = желаю счастья. Baxt = счастье. Tilamoq = желать. Sog'lik tilayman = желаю здоровья. Omad tilayman = желаю удачи. Tilaklarim = мои пожелания. В праздник принято говорить: Oilangizga baxt tilayman = желаю счастья вашей семье (oila = семья, из урока 7).

Спираль: вежливые формы из урока 4 (Rahmat, Marhamat), семья из урока 7 (oila, ota, ona), дни недели из урока 8 (kun), еда из урока 26 (palov, non, meva).

## Мини-диалог

— Navro'z muborak!
— Rahmat! Sizni ham tabriklayman!
— Baxt tilayman oilangizga!
— Katta rahmat! Keling, dasturxonga marhamat.
— Sumalak bormi?
— Ha, bor! Onam pishirgan. Mazali!
— Bayram kuni doim yaxshi!

## Задание на дом

Yaqin odamingizga bayram tabrigi yozing. Masalan: "Navro'z muborak! Sizni tabriklayman! Oilangizga baxt va sog'lik tilayman!" Kamida uch gap yozing.
