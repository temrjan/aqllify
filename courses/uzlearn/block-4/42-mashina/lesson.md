## Грамматика (коротко)

Mashina = машина / автомобиль. Mening mashinam = моя машина (суффикс -m). Mashina haydamoq = водить машину. Mashina sotib olmoq = купить машину. Yangi mashina = новая машина, eski mashina = старая машина.

Benzin quyish = заправить бензин. Benzin = бензин. Quymoq = заливать. Benzin quyish kerak = нужно заправиться. Yoqilg'i = топливо. Yonilg'i stantsiyasi = заправочная станция (чаще говорят zapravka). Benzin qancha? = Сколько стоит бензин? Числа из урока 6 нужны для цен, деньги из урока 15 для оплаты.

Yuvish = мыть / мойка. Mashinani yuvish kerak = нужно помыть машину. Avtomoyka = автомойка. Mashinani yuvib bering = помойте машину (yuvib bering = помойте, вежливая просьба). Qancha turadi? = Сколько стоит? (из урока 15).

Buzildi = сломалось (от buzilmoq = ломаться, прошедшее время). Mashinam buzildi = моя машина сломалась. Dvigatel buzildi = двигатель сломался. Gildirak teshildi = колесо проколото (gildirak = колесо, teshilmoq = проколоться). Yordam kerak! = Нужна помощь!

Ta'mirxona = мастерская / автосервис (ta'mir = ремонт + xona = помещение, как oshxona из урока 25). Ta'mir qilmoq = ремонтировать. Ta'mir qiling, iltimos = почините, пожалуйста. Qancha vaqt ketadi? = Сколько времени займёт? Ta'mirdan keyin mashinani olib ketaman = после ремонта заберу машину.

Спираль: числа для пробега и цен из урока 6, деньги и цены из урока 15 (qancha turadi, so'm, to'lamoq), такси из урока 16 (haydovchi, bormoq).

## Задание на дом

Mashina haqida uch gap yozing: mashinangiz bormi, qanday mashina, nima qilish kerak. Masalan: "Mening mashinam bor. Eski mashina. Benzin quyish kerak va mashinani yuvish kerak."
