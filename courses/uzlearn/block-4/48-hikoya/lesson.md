## Грамматика (коротко)

Прошедшее время в узбекском образуется суффиксом -gan + man (для первого лица). Tug'ilmoq = рождаться, tug'ilganman = я родился. O'smoq = расти, o'sganman = я вырос. O'qimoq = учиться, o'qiganman = я учился.

Tug'ilganman = я родился. Men Toshkentda tug'ilganman = я родился в Ташкенте. Вспомни Men ...dan (урок 2) = я из... Суффикс -da для места: Toshkentda = в Ташкенте.

O'sganman = я вырос. Samarqandda o'sganman = я вырос в Самарканде. Oilam katta (урок 7) = моя семья большая. Katta oilada o'sganman = я вырос в большой семье.

Tajriba = опыт. Tajribam bor = у меня есть опыт (суффикс -m = мой, bor = есть). Ish tajribam bor = у меня есть опыт работы (ish из урока 30). Besh yillik tajribam bor = у меня пять лет опыта.

Maqsad = цель. Maqsadim = моя цель (суффикс -im). Mening maqsadim = моя цель. Maqsadim dasturchi bo'lish = моя цель стать программистом. Orzu va maqsad = мечта и цель (orzu из урока 47).

Hikoya = рассказ, история. O'z hikoyangizni aytib bering = расскажите свою историю. Hikoyam = мой рассказ. При рассказе о себе используй: tug'ilganman, o'sganman, o'qiganman, ishlaganman (я работал).

Спираль: знакомство (урок 2) для начала рассказа, семья (урок 7) для описания семьи, работа (урок 30) для карьеры, хобби (урок 32) для увлечений, путешествия (урок 43) для поездок.

## Мини-диалог

— O'zingiz haqingizda gapirib bering.
— Men Buxoroda tug'ilganman, Toshkentda o'sganman.
— Qaerda o'qigansiz?
— Universitetda o'qiganman. Dasturchiman.
— Ish tajribangiz bormi?
— Ha, uch yillik tajribam bor.
— Maqsadingiz nima?
— Katta kompaniyada ishlash — mening maqsadim.

## Задание на дом

O'z hikoyangni yoz: qaerda tug'ilgansiz, qaerda o'sgansiz, qaerda o'qigansiz, hozir nima ish qilasiz, maqsadingiz nima. Kamida 5 ta gap yoz. Masalan: "Men Toshkentda tug'ilganman. Toshkentda o'sganman. Universitetda o'qiganman..."
