## Грамматика (коротко)

Bola = ребёнок. Bolalar = дети (суффикс -lar для множественного числа). Mening bolam = мой ребёнок (суффикс -m). Bolalar bilan = с детьми (bilan = с, вместе).

O'ynamoq = играть. O'ynayman = я играю, o'ynaydi = он/она играет, o'ynaymiz = мы играем. Bolalar o'ynaydi = дети играют. Maydonchada o'ynaydi = играют на площадке (суффикс -da для места).

Maydoncha = площадка (от maydon = площадь + суффикс -cha уменьшительный). Bolalar maydonchasiga boramiz = мы пойдём на детскую площадку (суффикс -ga для направления).

Muzqaymoq = мороженое (muz = лёд + qaymoq = сливки). Muzqaymoq yeymiz = мы будем есть мороженое. Ranglar (урок 10): qizil muzqaymoq = красное (клубничное) мороженое, oq muzqaymoq = белое (пломбир).

Parkda = в парке (суффикс -da). Parkga boramiz = мы пойдём в парк (суффикс -ga). Park yoqtiraman (урок 32) = мне нравится парк. Oila bilan parkga borish = пойти в парк с семьёй (oila из урока 7).

Спираль: семья (урок 7) для описания кто с кем гуляет, цвета (урок 10) для описания предметов и игрушек, хобби (урок 32) для обсуждения любимых занятий детей.

## Мини-диалог

— Bugun bolalar bilan parkga boramizmi?
— Ha, boramiz! Maydonchada o'ynaymiz.
— Muzqaymoq olamizmi?
— Albatta! Bolalar muzqaymoqni yoqtiradi.
— Qizil yoki oq?
— Ikkalasini ham! Ketdik!

## Задание на дом

Bolalar bilan yoki oilang bilan parkga reja yoz: qaerga borasiz, nima qilasiz, nima yeysiz. Masalan: "Bugun bolalar bilan parkga boramiz. Maydonchada o'ynaymiz. Muzqaymoq yeymiz."
