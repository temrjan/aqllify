## Грамматика (коротко)

Sayohat = путешествие. Sayohat qilmoq = путешествовать. Sayohatga boraman = я еду в путешествие (суффикс -ga для направления). Sayohatchi = путешественник (суффикс -chi для профессии/занятия). Sayohat rejasi = план путешествия.

Chipta = билет. Chipta olmoq = купить билет. Bir chipta bering = дайте один билет. Ikki chipta olmoqchiman = хочу купить два билета (числа из урока 6). Chipta qancha? = Сколько стоит билет? Poyezd chiptasi = билет на поезд, samolyot chiptasi = билет на самолёт. Транспорт из урока 17: avtobus, poyezd, samolyot.

Mehmonxona = гостиница (mehmon = гость + xona = комната). Mehmonxonada qolmoq = остановиться в гостинице. Bir kechaga qancha? = Сколько за одну ночь? Bron qilmoq = забронировать. Mehmonxona qayerda? = Где гостиница? Направления из урока 18 помогут найти дорогу.

Samarqand = Самарканд, древний город на Великом шёлковом пути. Registon maydoni = площадь Регистан. Samarqandga bormoqchiman = хочу поехать в Самарканд. Samarqanddan Buxoroga = из Самарканда в Бухару (-dan для исходной точки, -ga для направления).

Buxoro = Бухара, ещё один древний город Узбекистана. Buxoroda ko'p tarixiy joylar bor = в Бухаре много исторических мест (tarixiy = исторический, joy = место). Xiva = Хива, Toshkent = Ташкент. O'zbekiston go'zal mamlakat = Узбекистан красивая страна.

Спираль: числа для цен и количества из урока 6, такси из урока 16 (haydovchi, bormoq, olib boring), транспорт из урока 17 (avtobus, poyezd, samolyot), направления из урока 18 (qayerda, to'g'ri, o'ngga, chapga).

## Задание на дом

O'zbekistonda sayohat rejasi tuzing. Qayerga borasiz, qanday transport, necha kunga. Masalan: "Toshkentdan Samarqandga poyezdda boraman. Ikki kun qolaman. Registon va Shohizinda ko'raman."
