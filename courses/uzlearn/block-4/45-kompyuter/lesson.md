## Грамматика (коротко)

Kompyuter = компьютер. Noutbuk = ноутбук. Telefon = телефон (из урока 19). Kompyuterim = мой компьютер (суффикс -im). Kompyuterda ishlayman = я работаю за компьютером.

Ishlamayapti = не работает (прямо сейчас). Суффикс -yapti означает действие в данный момент (из урока 28: yog'yapti = идёт дождь). Отрицание: ishla + ma + yapti = не работает. Kompyuter ishlamayapti = компьютер не работает. Telefon ishlamayapti = телефон не работает.

Internet = интернет. Internet bor = есть интернет. Internet yo'q = нет интернета (bor/yo'q из урока 3). Internet sekin = интернет медленный. Internet tez = интернет быстрый.

Wi-Fi paroli = пароль от Wi-Fi. Wi-Fi paroli nima? = Какой пароль от Wi-Fi? Parol = пароль. Wi-Fi parolini bering = дайте пароль от Wi-Fi. Вспомни из урока 19: raqam = номер, из урока 35: hisob raqam = номер счёта.

Zaryadka = зарядка, зарядное устройство. Zaryadka bor? = Есть зарядка? Telefon zaryadkasi = зарядка для телефона. Telefon zaryadda = телефон на зарядке. Zaryadka tugayapti = зарядка заканчивается.

Спираль: телефон и связь (урок 19) для обсуждения устройств, банк и финансы (урок 35) для онлайн-операций.
