## Грамматика (коротко)

Дополнительные слова о семье:

| Узбекский | Кириллица | Русский |
|-----------|-----------|---------|
| Opa | Опа | Старшая сестра |
| Buvi | Буви | Бабушка |
| Bobo | Бобо | Дедушка |

**Притяжательные суффиксы:**

**Mening** ... **-m** = мой/моя:
- Mening **otam** = мой папа
- Mening **onam** = моя мама
- Mening **akam** = мой старший брат

**Sizning** ... **-ngiz** = ваш/ваша:
- Sizning **otangiz** = ваш папа
- Sizning **onangiz** = ваша мама
- Sizning **akangiz** = ваш старший брат

**Спираль:** Salom (привет) из урока 1, Yaxshimisiz? (как дела?) из урока 2, числа из урока 5 — «Mening ikkita akam bor» (у меня два старших брата).

## Мини-диалог

— Salom! Oilang katta-mi?
— Ha, katta. Mening ikkita akam va bitta singlim bor.
— Otangiz nima ish qiladi?
— Otam shifokor.

## Задание на дом

Назови всех членов семьи по-узбекски: ota, ona, aka, uka, singil, opa, buvi, bobo.
