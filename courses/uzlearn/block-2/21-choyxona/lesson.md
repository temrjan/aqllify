## Фразы

| Узбекский | Кириллица | Русский |
|-----------|-----------|---------|
| Choy bering | Чой беринг | Дайте чай |
| Palov bormi? | Палов борми? | Плов есть? |
| Non bering | Нон беринг | Дайте лепёшку |
| Issiq / Sovuq | Иссиқ / Совуқ | Горячий / Холодный |
| Yaxshi dam oling | Яхши дам олинг | Хорошего отдыха |

## Грамматика (коротко)

Choy = чай, Non = хлеб/лепёшка, Palov = плов. Это основные слова узбекской кухни. Bering = дайте (вспомни из урока 20).

Bormi? = есть ли? Суффикс -mi превращает утверждение в вопрос: Palov bor (плов есть) превращается в Palov bormi? (плов есть?). Этот приём из урока 3 с Ha / Yo'q.

Issiq = горячий, Sovuq = холодный. Choy issiq = чай горячий. Suv sovuq = вода холодная. Suv = вода.

Dam olmoq = отдыхать. Yaxshi dam oling = хорошего отдыха (вежливое пожелание). Oling = берите/принимайте (вежливая форма от olmoq).

Спираль: Iltimos и Rahmat из урока 4 при заказе, числа из урока 5 для количества (ikkita choy = два чая), Bering и Mazali из урока 20.

## Мини-диалог

— Assalomu alaykum! Uchta choy bering, iltimos.
— Marhamat! Palov bormi?
— Ha, palov va non bering.
— Choy issiq. Ehtiyot bo'ling!
— Rahmat! Juda mazali!
— Yaxshi dam oling!

## Задание на дом

Закажи воображаемый обед в чайхане: скажи вслух "Ikkita choy va bitta palov bering, iltimos."
