## Грамматика (коротко)

Qayerda? — где? Bekat — остановка. Bekat qayerda? = Где остановка? Вопросительное слово qayerda всегда стоит в конце.

Qaysi? — какой? / который? Qaysi avtobus? = Какой автобус? Qaysi bekat? = Какая остановка?

Keyingi — следующий. Keyingi bekat = следующая остановка. Oldingi — предыдущий.

Chipta — билет. Chipta qancha? = Сколько стоит билет? Bitta chipta bering = Дайте один билет.

Bormi? — вопрос наличия из урока 14. Metro bormi? = Метро есть? Avtobus bormi? = Автобус есть?

Спираль: вежливые слова Iltimos, Rahmat, Kechirasiz (урок 4), числа для оплаты (урок 6), to'xtang и gacha из урока 16.
