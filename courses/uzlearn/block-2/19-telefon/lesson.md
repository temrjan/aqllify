## Грамматика (коротко)

Telefon raqamingiz necha? = Какой ваш номер телефона? Слово raqam означает номер, а суффикс -ingiz делает его вежливым обращением: raqam + ingiz = raqamingiz (ваш номер).

Qo'ng'iroq qilmoq = звонить. Qo'ng'iroq qiling = позвоните (вежливая просьба). Суффикс -ing на конце глагола создаёт вежливую форму повеления.

Yozing menga = напишите мне. Yozmoq = писать, menga = мне. Тот же суффикс -ing для вежливой просьбы.

Bor = есть (имеется). Yo'q = нет (не имеется). Вспомни Ha / Yo'q из урока 3: WhatsApp bor = WhatsApp есть, Aloqa yo'q = связи нет.

Спираль: числа из уроков 5 и 6 нужны для диктовки номеров. Tanishish (урок 2) — при обмене контактами с новым знакомым.
